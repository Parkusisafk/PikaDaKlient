- Auto Mining (with custom enchantments enabled) -->StartCommand="sp", EndCommand="ep"
- Auto Abyss Mining (requires baritone) -->StartCommand="sa||as", EndCommand="ea||ae"
- Auto Reconnect & Setup (requires Autoreconnect, preferably with Meteor Client)
- Auto Ascensions
- Auto Key Opener -->Command="okey", make sure to look at a chest, assumption = Gangster Rank
- Log Scoreboard -->Command="ps"
- Custom tracker screen as seen above to keep track of progress and if the bot is stuck/broken
